Yoga Reservas 0.1.1-pub

Prototipo local de reservas para un estudio de yoga. Se ejecuta solo en tu PC, sin internet y sin instalar nada.

Descargar el ZIP para Windows

Archivo: yoga-reservas-0.1.1-pub-windows.zip
Tamaño: 35.014.737 bytes (33,4 MiB)
SHA-256: d4bdc404013269ddbc4a79e85fb31f5a87e06a49261fe44fc7642c4199e9a841

Código y releases: github.com/dastok1000/app-yoga.

Es un prototipo. Los pagos están simulados: no se cobra nada ni se conecta a ninguna pasarela real. Los avisos se guardan en la propia app; no se envían correos ni SMS.

Windows puede mostrar SmartScreen al abrir un .bat descargado de internet. Si has comprobado el hash del ZIP y confías en la descarga, elige «Más información» y luego «Ejecutar de todas formas».

Comprobar el hash del ZIP

En el Símbolo del sistema (cmd):

certutil -hashfile yoga-reservas-0.1.1-pub-windows.zip SHA256

En PowerShell:

Get-FileHash yoga-reservas-0.1.1-pub-windows.zip -Algorithm SHA256

El resultado debe coincidir con d4bdc404013269ddbc4a79e85fb31f5a87e06a49261fe44fc7642c4199e9a841.

Instalar y arrancar

  1. Descomprime el ZIP entero en una carpeta.
  2. Haz doble clic en Abrir.bat. Se abre una consola (el servidor) y el navegador en http://127.0.0.1:8795/. El servidor escucha solo en este PC (127.0.0.1). El puerto se puede cambiar con YOGA_PORT.
  3. En el primer arranque no hay usuarios. Crea tú la cuenta de administración. El horario empieza vacío.
  4. Deja la ventana abierta mientras uses la app; ciérrala para parar.

El ZIP incluye el runtime oficial de Node.js v24.22.1 para Windows (x64). Su licencia (MIT y licencias de terceros) está en yoga-reservas/runtime/LICENSE.

Actualizar sin perder datos (U1–U3)

  1. U1. Cierra la app (cierra la ventana o Ctrl+C) y espera a que desaparezca.
  2. U2. Copia la carpeta data\ entera (incluidos yoga.db, yoga.db-wal, yoga.db-shm y avisos.log si existen) a la carpeta de la versión nueva. No abras aún la versión nueva en otra carpeta: se crearía una base vacía.
  3. U3. Entonces ejecuta Abrir.bat de la carpeta nueva.

No uses Restablecer-datos.bat al actualizar: borra todos los datos. Ese archivo solo sirve si quieres empezar de cero; no crea usuarios de ejemplo.

Las instrucciones completas están en el README.md del ZIP y en el repositorio.
